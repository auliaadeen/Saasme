# Contributing

Lab follows Spec-Driven Development.

Before implementing a non-trivial feature:

1. Define or update the specification.
2. Clarify ambiguous requirements.
3. Produce an implementation plan.
4. Break the plan into tasks.
5. Analyze cross-artifact consistency.
6. Implement.
7. Test and converge against the specification.

Pull requests should reference the relevant specification, explain behavior changes, include tests for critical behavior, avoid unrelated changes, and contain no secrets or private user content.

For vulnerabilities, follow SECURITY.md rather than opening a public issue.
